# SIH Sikkim Monastery Project

The SIH Sikkim Monastery Project is a frontend-based web platform developed as part of the Smart India Hackathon initiative to promote the cultural heritage and tourism of Sikkim monasteries. The website provides users with detailed monastery information, travel guidance, accommodation details, itineraries, and an interactive browsing experience through a responsive and user-friendly interface.

## Features
- Interactive and Responsive User Interface
- Monastery Information Pages
- Tourism and Cultural Awareness
- Travel Itinerary Planning
- Accommodation Information
- Image Gallery and Visual Content
- User-Friendly Navigation

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- Frontend: HTML, CSS, JavaScript
- Assets: Images and Media Files

## Objective
The objective of this project is to digitally promote Sikkim monasteries and improve accessibility to tourism and cultural information through an informative and visually engaging web platform.

## Pages Included
- Home Page
- Monastery Information Pages
- Itinerary Planning Page
- Accommodation Page
- Event/Calendar Page

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder.
3. Run the `home.html` or `index.html` file in any web browser.
